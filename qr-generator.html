🥌 Curling Timer X

Generate a QR code for your Rabbit R1 device

📱 How to use on Rabbit R1:

  1. Select the QR Code Mode (Rabbit R1 Metadata recommended)
  2. Fill in the app details if using JSON mode
  3. Click "Generate QR Code" above
  4. Print or display this QR code on your screen
  5. Open the camera or QR scanner on your Rabbit R1
  6. Point it at the QR code
  7. The Curling Timer app will open or install

🔧 QR Code Modes:

  1. Rabbit R1 Metadata (JSON): Contains full app information including title, description, icon, and screenshot URLs. Recommended for Rabbit R1 devices.
  2. Simple URL: Just encodes the URL. Compatible with any QR scanner.

🌐 Alternative Options:

  1. Python Script: Use the included generate-rabbit-qr.py script
  2. Command Line: Run python3 generate-rabbit-qr.py to generate from rabbit-metadata.json
  3. Direct URL: Manually enter the URL on your Rabbit R1 browser
